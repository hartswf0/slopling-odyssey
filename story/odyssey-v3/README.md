## Connect to production assets

Use the [packet crosswalk](../../registry/story/ODYSSEY_V3_PACKET_CROSSWALK.json) to locate candidate existing cutout packets. These are semantic suggestions, not confirmed rig bindings. Choose and inspect a compatible source bank and view before assembly. Do not recut these JPEG sheets when suitable native transparent PNGs already exist.

Use the [scene dependency list](../../registry/story/ODYSSEY_V3_SCENE_DEPENDENCIES.json) to find each beat's authored kit requirements and transitions. Neither this list nor the viewers run an agent swarm.

The [import record](../../registry/story/ODYSSEY_V3_IMPORT.json) records source hashes, observed counts, missing dependencies, and unresolved transition targets. Authored claims of 947 pieces and 528 pivots are not measurements of extracted usable parts. Film citations, quotations, and rights assertions remain unverified source material.

[SOURCE_README.md](SOURCE_README.md) preserves the uploaded guide, including its original layout assumptions. The original push helper is archived as text in `sources/`; use the existing repository history for subsequent changes. Original repeated filenames remain available for source compatibility.
