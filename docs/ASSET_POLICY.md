# Asset handling

1. Search the inventory before generating or redrawing a part.
2. Preserve native PNG bytes. Record repairs as new versions with source links.
3. Select a character, one source bank and compatible view before assembly.
4. Keep unspecified views and unrecorded lighting explicit.
5. Keep original dimensions, anchors, source paths and hashes with every selection.
6. Require a named motion test before recording a part as tested.
7. Do not treat excluded animation experiments as original production art.

Repeated bytes are stored once in the organized packets. Character bindings can share a design. Inventory counts are not claims of distinct likenesses, complete rigs, or successful animation.
