# Source provenance

The registry records original archive filenames, member paths, dimensions, original asset IDs, recorded joints, and verified SHA-256 hashes. The native source images are inside the repository archive chunks; restore them with `python3 tools/restore_packets.py`.

The recovered inputs were Slopling_Production_Part_1_of_3.zip, Slopling_Production_Part_2_of_3.zip, Slopling_Production_Part_3_of_3.zip, All_Cast_Scale_Matched_Parts.zip, and Watson_Rig_and_Motion_v2.zip. These larger upstream archives are not duplicated here in addition to the organized packets.

Catalogs may include locators for large non-cutout reference sheets retained in those upstream archives. Every catalogued original cutout, historical scale PNG, family reference and working Watson card is included in the organized packets. A reference-sheet record is not necessarily an individual runtime part.

The repository's public catalogs point here rather than to private ChatGPT Library download URLs. Historical ZIPs are preserved byte-for-byte, so any Library links inside those historical documents still require their original owner's account. They are not needed to restore the included PNG files.

No blanket license has been assigned. Reference imagery can have different owners; inspect its provenance before reuse.
